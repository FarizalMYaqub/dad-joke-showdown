My son asked for dinner I couldn't possibly burn, so I made reservations. This program writes that one dad joke to `/output/entry.txt` for the judge — the joke itself is the whole entry, nothing more. It stays inside the gate: one joke, 73 characters, with the punchline saved for the very last word. The setup is the classic dad confession (Dad burns dinner); the punchline is the dad-shaped escape hatch, booking a table instead of cooking.

## Run

```sh
python3 main.py
```
